# MDRE for VS Code 0.2.5 更新说明

适用：VS Code 1.95.0 或更高版本。桌面版与插件版版本号均为 0.2.5；本次更新集中在图片管理、可分享副本、剪贴板互通与表格操作，两版功能保持一致。

## 安装

下载 `mdre-vscode-0.2.5.vsix`，在 VS Code 执行“扩展：从 VSIX 安装…”，或运行：

```powershell
code --install-extension ".\mdre-vscode-0.2.5.vsix" --force
```

安装后重新加载 VS Code。PDF 导出需要系统安装 Microsoft Edge 或 Google Chrome；自动检测失败时，在 VS Code 设置中填写 `mdre.pdf.browserPath`。

## 图片管理

- 侧栏新增“图片管理”，与“大纲导航”同区，按当前渲染文档的**引用顺序**列出所引用的图片：图片名称与图片在电脑中的路径。名称过长时以省略号显示，悬停可查看完整内容；图片较多时可在面板内滚动查看。
- 单击条目，渲染栏滚动到对应图片并选中该位置；双击图片名称打开图片所在目录。面板随文档切换与预览刷新自动更新；当前文档未引用图片时显示空状态。

## 可分享副本

- “导出”菜单新增“导出可分享副本…”：把 Markdown 文档与被引用的图片打包为一个 zip 文件，Markdown 中的图片引用改写为 zip 内的相对路径；原文档与源图片不变。
- 原本位于文档目录内、使用相对路径的图片保持原相对路径；绝对路径与全局图片库中的图片按内容哈希命名放入 zip 内的 `images/` 目录并改写引用；无法读取的图片跳过，并在状态栏提示数量。HTTPS 图片与内嵌 data URI 图片不写入 zip。

## 剪贴板与轻量互通

### 复制为富文本

- 渲染栏右键菜单“复制／剪切／粘贴”区域新增“复制为富文本”，快捷键 **Ctrl+Shift+C**：有选区时复制选区，无选区时复制整篇渲染内容。源码栏的复制行为保持不变，仍输出纯 Markdown。
- 复制时同时写入 `text/html` 与 `text/plain`，保留标题、段落、粗体、斜体、下划线、删除线、列表、任务清单、引用、代码、链接、表格和图片；不包含页码、代码行号、纸张边距等界面装饰。
- MDRE 私有语法按最接近的语义降级：文字颜色处理为下划线，高亮与字号处理为加粗；无法映射的内容丢弃并在状态栏提示。优先使用 `navigator.clipboard`，失败或被拒时使用隐藏编辑区加 `execCommand` 兜底。

### 粘贴 HTML

- 源码栏和渲染栏继续使用 **Ctrl+V** 粘贴：剪贴板包含 HTML 时自动转换为 Markdown，没有 HTML 或转换失败时按纯文本粘贴。不新增顶部按钮和设置项，转换结果与忽略项通过状态栏提示。
- 识别标题、段落、加粗、斜体、下划线、删除线、列表、引用、代码块、链接、表格、换行，以及 Word 常见的 `MsoHeading*` 标题、`mso-list` 列表和 Excel／网页表格；颜色、字体、字号、行距、对齐等无法表达的格式忽略并提示“已忽略 N 项格式”。
- 合并单元格表格降级为普通段落并提示。转换前对 HTML 做白名单清洗，脚本、iframe、事件属性一律丢弃；转换结果经模型校验后回写源码，一次粘贴只产生一步撤销。
- 图片处理：Word 内嵌的 data URI 图片存入全局图片库（按内容哈希去重、引用绝对路径）；网页 HTTPS 图片保留链接；无法读取的 Word 临时文件图片跳过并提示。HTML 超过 5 MB 或图片超过 20 张时回退为纯文本粘贴。
- 源码栏按光标插入，渲染栏按选区替换；代码块和行内代码内粘贴按纯文本处理，表格单元格内粘贴复杂内容降级为文本。右键“粘贴”菜单同样优先进行 HTML 转换（Ctrl+V 最可靠）。

## 表格操作

- **列宽**：渲染表格的列边框在鼠标悬停时显示调整光标，拖动可调整列宽并实时预览，松开后一次提交（算一步撤销）；双击列边框按该列内容适应宽度。右键“表格”菜单新增“均分各列”“适应内容”“恢复自动列宽”三项。列宽以百分比计算，单列最小 4%，总宽保持 100%。
- **对齐**：水平对齐保留左对齐、左右居中、右对齐并保持互斥，勾选表示当前状态。GFM 表格把对齐写入分隔行，只影响选中单元格所在列；HTML 表格写入单元格 `text-align` 样式。新增“上下居中”复选框，作为独立开关，可与任一水平对齐同时生效。
- **合并与拆分**：合并只接受矩形区域，按阅读顺序用换行合并选中内容；拆分后内容留在左上单元格。首次合并或首次启用“上下居中”时，整表转为 HTML 表格并提示“此表已转为 HTML 表格，其他仅支持标准 Markdown 表格的编辑器可能显示源码”。
- **转换为 Markdown 表格**：仅对无合并、无上下居中的 HTML 表格可用；执行前会列出会丢失的信息并需确认。列宽保留为 HTML 注释，水平对齐按每列首行样式写回分隔行。
- **列宽注释**：手动调整的列宽写在表格后的 HTML 注释中，例如 `<!-- mdre:table-widths: 25%,40%,35% -->`，其他 Markdown 编辑器会当作注释忽略。插删列会同步更新注释；列数或注释数量不匹配时回退自动布局并提示。
- **导出**：HTML／PDF 导出保留列宽、合并单元格与水平／垂直对齐；合并单元格禁止跨页拆开。

## 已知限制

- 合并单元格、上下居中的表格会保存为 HTML 表格，手动列宽会保存为 `mdre:table-widths` 注释。其他仅支持标准 Markdown 表格的编辑器可能把 HTML 表格或注释直接显示为源码，编辑保存后可能丢失这部分格式。
- 复制为富文本时图片以 data URI 形式写入剪贴板。粘贴到 Word 等应用时是否接受 data URI 图片取决于目标应用的兼容性；若不显示，可改用已内嵌图片的 HTML／PDF 导出，或使用可分享副本。
- 从网页或 Word 粘贴时，HTTPS 图片保留为链接，离线后可能无法显示；转换只承诺支持上文列出的 HTML 子集，`mso-*`、VML、SVG、MathML 和复杂表格会被忽略或降级。
- 列宽为 MDRE 显示设置，其他编辑器不识别该注释时按自动列宽显示。
- PDF 导出调用系统 Edge 或 Chrome；缺少浏览器时需要先安装，或在设置中指定 `mdre.pdf.browserPath`。
