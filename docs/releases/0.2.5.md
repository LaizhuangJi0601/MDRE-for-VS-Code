# MDRE for VS Code 0.2.5

This release adds image management, shareable copies, clipboard interop and richer table operations.

## What's new

- **Image management:** a sidebar tab lists referenced images in document order with names and paths; click an entry to jump to the reference, double-click to open the containing folder, and the list follows document switches and preview refreshes.
- **Shareable copy:** export the Markdown document and referenced images as a ZIP with rewritten relative image paths; images with absolute paths or in the global store are collected by content hash, unreadable images are skipped, and the original document is not changed.
- **Copy as rich text:** Ctrl+Shift+C copies the selection, or the whole rendered document when nothing is selected, as HTML and plain text with headings, lists, quotes, code, links, tables and images; private MDRE formatting degrades to the closest standard formatting.
- **Paste HTML:** Ctrl+V converts clipboard HTML to Markdown in both panes, recognizing Word headings/lists and Excel or web tables while ignoring colors, fonts and spacing with an ignored-format count; each paste is one undo step.
- **Table operations:** drag column borders to resize (double-click fits content), align cells horizontally and vertically, merge and split rectangular selections, and convert HTML tables back to Markdown; HTML/PDF export keeps widths, merges and alignment.
- **Known limits:** merged or vertically centered tables are stored as HTML and manual widths as `mdre:table-widths` comments, which other Markdown editors may show as source.

## Installation

Install `mdre-vscode-0.2.5.vsix` with **Extensions: Install from VSIX** in VS Code 1.95 or later, or run:

```powershell
code --install-extension ".\mdre-vscode-0.2.5.vsix" --force
```

Reload VS Code after installing. PDF export requires system Edge or Chrome; set `mdre.pdf.browserPath` if detection fails. Verify downloads with `SHA256SUMS.txt`.
