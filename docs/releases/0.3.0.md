# MDRE for VS Code 0.3.0

This release adds PDF, Word, text and code files alongside Markdown, interface scaling, update checks, a relocated Find bar, immediate settings, and shorter transitions.

## What's new

- **PDF viewer:** open PDF files inside the app with 10%–400% zoom, 5% buttons, 0.1% Ctrl+wheel stepping, a page indicator, and page thumbnails with numbers in the Outline sidebar. Large files are read on demand, and editing controls plus character and cursor statistics are hidden while viewing.
- **Word, text and code files:** read Word documents in a continuous read-only view with heading navigation; open plain text and common code files with language highlighting, line numbers, editing, saving and your font settings.
- **Interface scale:** enlarge the title bar, menus, toolbar, sidebar, status bar, Find bar and dialogs from 80% to 200% in 10% steps with the dropdown, −/+ buttons or Ctrl+wheel, without changing body text. The choice applies immediately and is remembered.
- **Update checks:** the desktop edition checks the latest GitHub release from the version button next to Help or from Settings. Checking opens a dedicated window with the same window controls, remembered position and size as the settings and help windows; it lists the current and latest versions, publication date, download size and release notes, follows the interface language, and offers Restart now or Restart later after downloading and verifying `mdre.exe`. A new release also shows a blue dot on the version button. Automatic checks run at 12:00 each day and catch up on the next launch.
- **Settings:** changes take effect and save immediately. Apply and Cancel are gone, and the page stays open until closed.
- **Find:** search and replace open above the document instead of reserving sidebar space, with matching previous and next arrows.
- **Transitions and flicker:** in-place fades run for about 0.4 seconds, and remaining multi-frame flashes during common operations are removed.
- **Files:** file lists, open dialogs and drag-and-drop accept Markdown, text, code, PDF and Word documents.

## Installation

Download `mdre.exe` and run it on Windows 10/11 x64 with the Microsoft Edge WebView2 Runtime installed. Verify the download with `SHA256SUMS.txt`.

The VS Code extension is distributed separately as `mdre-vscode-0.3.0.vsix`. Install it with `code --install-extension mdre-vscode-0.3.0.vsix`, then open Markdown files with **MDRE Split Editor**, or use the MDRE open command for PDF, Word, text and code files.

Word conversion uses an external Pandoc installation. The Word viewer renders locally and may simplify equations or complex layouts.
