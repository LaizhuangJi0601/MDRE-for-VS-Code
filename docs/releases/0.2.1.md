# MDRE for VS Code 0.2.1

## What's new

- **Tables:** align cell content left, center or right from the table context menu, with the current alignment indicated.
- **Toolbar and settings:** the formatting toolbar is available at the top with settings and export on the right; help lives in the settings window and settings use a responsive layout.
- **Context menus:** grouped by text formatting, tables and block operations.
- **Theme and navigation:** restored the startup theme and added VS Code theme following; fixed in-page links and heading anchors, and the outline follows the reading position.
- **Parsing fixes:** documents containing superscripts, subscripts, links or images no longer fail to open; horizontal rules and HTML source editing are improved.

## Installation

Install `mdre-vscode-0.2.1.vsix` with **Extensions: Install from VSIX** in VS Code 1.95 or later, or run:

```powershell
code --install-extension ".\mdre-vscode-0.2.1.vsix" --force
```

Reload VS Code, then open Markdown files with **MDRE: Open split editor**. PDF export requires Microsoft Edge or Google Chrome.
