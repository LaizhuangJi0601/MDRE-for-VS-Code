# MDRE for VS Code 0.2.4 更新说明

适用：VS Code 1.95.0 或更高版本。0.2.4 为公共发布版，汇总 0.2.2、0.2.3 的全部更新（GitHub 发布跳过 0.2.2 与 0.2.3），并修复本地绝对路径图片的 HTML／PDF 导出问题。

## 安装

下载 `mdre-vscode-0.2.4.vsix`，在 VS Code 执行“扩展：从 VSIX 安装…”，或运行：

```powershell
code --install-extension ".\mdre-vscode-0.2.4.vsix" --force
```

安装后重新加载 VS Code。PDF 导出需要系统安装 Microsoft Edge 或 Google Chrome；自动检测失败时，在 VS Code 设置中填写 `mdre.pdf.browserPath`。
## 编辑与保存

- 修复有序列表、无序列表和任务清单空项退格与退出列表时的回写问题；列表内部的额外空段使用 `<p></p>` 保留。
- 普通数字开头段落统一使用 `1\.` 等可读转义；原有数字实体继续兼容。直接在源码写 `1. 内容` 或独占一行的 `1.` 仍按 Markdown 有序列表解释。
- 分隔线可点击选中后用 Delete／Backspace 删除；块删除、表格及跨段编辑继续进行重新解析校验。
- 字号单位可在“外观与阅读”中选择 px／em，默认 px；切换单位换算正文字号，保持实际大小。工具栏及右键仅展示所选单位；px 预设为 8、10、12、14、16、18、20、22、24px。
- 右键菜单依次为文字格式、文字颜色、标题、高亮、字号、插入、表格、块操作；复制至重做的位置与功能保留。
- 两端支持全选表格、拖动文本选区、Ctrl／Cmd 点击多选、Shift 点击矩形选区后批量对齐；一次修改可一次撤销。
- 修复插件每 60 秒自动保存未启动的问题，保存通过 VS Code 原生文档确认；桌面版同步检查。无正式路径、正在组合输入、恢复副本或冲突中的文档不会被定时器强行覆盖。

## 视图与查找

- 新增默认侧栏状态、编辑功能区显示状态。
- 右下角可选择全量编辑、专注模式、沉浸专注、A4视图；已合并重复的编辑视图选项。手动修改为其他组合时显示自由模式，重新打开恢复最后组合。
- 专注模式仍保留底部信息栏，可随时切换视图；F11 在专注模式和全量编辑之间切换。
- 插件隐藏编辑功能区后，在右下角保留导出和设置图标。
- 保存状态移到左侧文件名之后；右侧依次显示字符与词数、编码、行列、视图和编辑／阅读模式。
- 查找框加宽，新增上一个匹配，支持 Shift+Enter；跳转时自动滚动到匹配内容。
- 帮助表格支持按空间换行，避免代码与文字遮挡；同步更新离线帮助与 README。

## 导出与安装

- 修复 HTML／PDF 导出将 `<file:///...>` 本地绝对路径图片误判为未解析的问题：现在会读取图片并内嵌到导出文件；相对路径、HTTPS 与内嵌图片的行为不变。
- PDF 导出先选择“分页导出”（A4）或“长页导出”（全文单页）。长页长度由实际排版测量；超过系统打印引擎单页长度上限时提示改用分页，避免截断正文。
- HTML 导出保留原有流程。桌面使用 WebView2；插件使用系统 Edge／Chrome。
- Windows 运行 `MDRE.exe`；VS Code 通过“从 VSIX 安装…”安装 `mdre-vscode-0.2.4.vsix`。
- 同目录的 `SHA256SUMS.txt` 用于核对 EXE 和 VSIX。编译中间产物在验收后清理。

## 0.2.2 与 0.2.3 汇总内容

- 0.2.2：应用与插件使用透明 MD 字母 Logo；Markdown 文件关联图标独立为折角纸张图标。
- 0.2.3：视图预设与自由组合恢复、px／em 字号单位、表格多选批量对齐、查找上一个匹配、PDF 分页／长页导出、插件自动保存修复、空列表项／数字段落／分隔线删除修复。
