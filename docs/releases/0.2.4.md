# MDRE for VS Code 0.2.4

This release improves editing stability, tables, typography, views, search and export, and fixes HTML/PDF export of local images referenced by absolute paths.

## What's new

- **Editing:** fixed list and task-list backspace and exit behavior, numeric paragraphs (`1\.`), and stable block deletion for rules, tables and cross-paragraph selections.
- **Typography:** px or em font-size units under Appearance & reading, with the toolbar and menus showing only the selected unit.
- **Tables and menus:** grouped context menus; select whole tables, drag, Ctrl/Cmd-click or Shift-click rectangular ranges and align them in one undoable step.
- **Views and status:** default sidebar and toolbar visibility, four view presets with a free mode, F11 focus toggle, and save status, character/word counts, encoding and line/column in the status bar.
- **Search and help:** wider find box with previous match (Shift+Enter), automatic scrolling to matches, and wrapping help tables.
- **Export:** embed local images referenced by `<file:///...>` URLs in HTML/PDF; choose paged (A4) or long-page PDF, with a hint when a long page exceeds the print engine limit.
- **Branding and refinements:** a transparent MD logo and a dedicated document icon, view presets with restored combinations, batch table alignment, previous-match search, paged and long-page PDF export, an autosave fix, and list, paragraph and rule fixes.

## Installation

Install `mdre-vscode-0.2.4.vsix` with **Extensions: Install from VSIX** in VS Code 1.95 or later, or run:

```powershell
code --install-extension ".\mdre-vscode-0.2.4.vsix" --force
```

Reload VS Code after installing. PDF export requires system Edge or Chrome; set `mdre.pdf.browserPath` if detection fails. Verify downloads with `SHA256SUMS.txt`.
