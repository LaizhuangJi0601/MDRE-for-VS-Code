# MDRE for VS Code 0.2.7

This release brings more reliable diagrams, smoother view transitions, an in-editor settings popup, cleaner Word export, a remembered A4 zoom level, window position memory, system fonts, faster large-document editing, and better links and anchors.

## What's new

- **Mermaid reliability:** diagram source is normalized into valid SVG before display, so labels with `<br/>` line breaks, Chinese text, quotes or parentheses render reliably. Common diagram types are covered, and invalid syntax shows a readable hint instead of the raw source.
- **In-place cross-fade transitions:** view, tab, dialog, menu, theme and mode changes cross-fade in place for about 0.8 seconds, without sliding or fly-in motion; flickers are fixed and composition input is untouched.
- **Settings popup:** settings open as a popup inside the editor instead of a separate VS Code editor page. Settings and help dialogs remember their last position and size.
- **Word export:** exported `.docx` files follow the Markdown content and no longer prepend a generated title such as "MDRE document snapshot".
- **Reading layout:** the A4 zoom level (25%–250%) is remembered globally and reused for every document you open.
- **Fonts and help:** font pickers list fonts installed on the system; the offline-help footer is removed so the content area gets more room.
- **Large documents and links:** parsing is about 40–45% faster and per-keystroke main-thread work drops by about 64% for 130 KB-scale documents; in-page anchors and relative `.md` links work consistently.

## Installation

Install `mdre-vscode-0.2.7.vsix` using **Extensions: Install from VSIX** in VS Code 1.95 or later. PDF export requires Edge or Chrome; Word conversion requires [Pandoc](https://pandoc.org/installing.html). Verify the download with `SHA256SUMS.txt`.
