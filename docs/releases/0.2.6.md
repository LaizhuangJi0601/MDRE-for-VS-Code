# MDRE for VS Code 0.2.6

## What's new

- Word import and export through Pandoc, including common structures and equations.
- English and Simplified Chinese interfaces, categorized settings, and searchable offline help with chapter navigation.
- Improved settings draft recovery, dialog controls, resizing, and configurable fade transitions.
- Adjustable 60%–100% reading width outside A4, four text alignments, and image display preferences across layouts.
- Improved selection-wide formatting, table menus, and composition input handling.
- Smaller font resources and on-demand loading; extension details and changelog are now in English.

## Installation

Install `mdre-vscode-0.2.6.vsix` using **Extensions: Install from VSIX** in VS Code 1.95 or later. PDF export requires Edge or Chrome; Word conversion requires [Pandoc](https://pandoc.org/installing.html). Verify the download with `SHA256SUMS.txt`.
