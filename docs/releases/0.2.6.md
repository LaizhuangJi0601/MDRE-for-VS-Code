# MDRE 0.2.6 · updata2

The desktop app and VS Code extension share version 0.2.6. This update brings English and Simplified Chinese interfaces, Word conversion through external Pandoc, and a reorganized workspace.

- Import and export Word documents (`.docx`) with a separately installed Pandoc. Select the complete executable path, including `pandoc.exe` on Windows. Pandoc is not bundled; TeX conversion is not included. Review converted documents when the source uses complex layouts.
- Browse categorized settings with search, a reading preview, and apply/reset controls. Use searchable offline guides with chapter navigation. Desktop settings, help, and shortcuts open in dedicated windows; extension dialogs have consistent window controls.
- Adjust non-A4 reading width from 60% to 100%, choose justified/left/center/right text alignment, and apply image display preferences in both paper and continuous layouts.
- Switch between English and Simplified Chinese for menus, settings, welcome content, messages, and all three help documents. Document text and original license notices retain their original language.
- Use configurable fade transitions that respect system preferences and composition input. Empty workspaces disable document-dependent exports.
- Desktop file watching detects external saves, preserves conflicting local edits, and remembers reading positions. Reopening the same path activates its existing tab.
- Source and rich-text edits support selection-wide paragraph formatting; table menus group insertion, deletion, merging, alignment, widths, and conversion.

## 中文

桌面版与 VS Code 插件内部版本均为 0.2.6。本次更新整合外部 Pandoc Word 互转、中英文界面、分类设置与离线帮助，以及阅读布局和窗口交互改进。

- Word 导入、导出调用独立安装的 Pandoc；路径须具体到可执行文件，Windows 为 `pandoc.exe`。程序包不捆绑 Pandoc，不提供 TeX 互转；复杂 Word 版式可能简化。
- 设置支持分类、搜索、阅读预览与应用／恢复默认；帮助提供文档分类、章节目录与搜索。桌面设置、帮助和快捷键使用独立窗口，插件内弹窗统一窗口控件。
- 非 A4 阅读宽度为 60%–100%，支持两端、左、居中和右对齐；图片默认显示方式适用于 A4 与非 A4。
- 简体中文与 English 覆盖界面、提示和三篇离线帮助；文档原文与许可原文保留。
- 淡入淡出动画可配置并跟随系统偏好，兼顾组合输入；未打开文档时禁用相关导出入口。
- 桌面同步外部文件保存、保留本地冲突内容，并恢复阅读位置；同一路径重复打开时激活已有标签。
- 标题与段落格式支持批量选区，表格菜单按操作类别分组。
