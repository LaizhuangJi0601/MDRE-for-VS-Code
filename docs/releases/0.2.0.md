# MDRE for VS Code 0.2.0

The first release of MDRE as a standalone VS Code extension.

## What's new

- **Synchronized editing:** edit rich text while the Markdown source stays in sync, using VS Code's saving, autosave, undo and redo.
- **Formatting and content:** formatting tools, tables, images, links, syntax highlighting, visual equation editing and Mermaid diagrams.
- **A4 layout:** continuous and paged A4 views with 25%–250% zoom, up to three pages per row, page numbers and body alignment.
- **Outline and settings:** outline entries keep their height and scroll within the panel; the sidebar and settings share a consistent experience.

## Installation

Install `mdre-vscode-0.2.0.vsix` with **Extensions: Install from VSIX** in VS Code 1.95 or later, or run:

```powershell
code --install-extension ".\mdre-vscode-0.2.0.vsix" --force
```

Reload VS Code after installing. PDF export requires Microsoft Edge or Google Chrome; the extension does not download Chromium.
