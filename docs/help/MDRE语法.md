# MDRE 语法说明

本页适用于 **MDRE 0.2.0**，说明该版本支持的 Markdown 语法及扩展写法。

- **标准语法**：CommonMark 规范定义的基本 Markdown 语法。
- **通用扩展**：其他 Markdown 工具中常见的扩展，如表格、任务列表和数学公式；不同工具的支持范围可能不同。
- **MDRE 扩展**：用于文字颜色、背景色、字号和图片宽度的专用写法；不支持这些写法的编辑器可能直接显示标记文本。

示例中的 `↵` 表示换行，连续两个 `↵` 表示空行。表内的语法标记应按示例写入 Markdown 源码。

| 语法 | 说明 | 分类 |
| --- | --- | --- |
| `# 一级标题` … `###### 六级标题` | 一至六级标题，井号后加空格。 | 标准语法 |
| `标题` ↵ `===`；`标题` ↵ `---` | Setext 式一级或二级标题：标题下一行分别使用等号或连字符标记。 | 标准语法 |
| `第一段` ↵  ↵ `第二段` | 段落间留一空行（↵ ↵）。 | 标准语法 |
| `第一行  ` ↵ `第二行` | 行末两个空格后换行。 | 标准语法 |
| `第一行\` ↵ `第二行` | 行末反斜杠后换行。 | 标准语法 |
| `**粗体**`；`__粗体__` | 加粗文字。 | 标准语法 |
| `*斜体*`；`_斜体_` | 斜体文字。 | 标准语法 |
| `***粗斜体***` | 同时加粗与斜体。 | 标准语法 |
| `> 引用`；`>> 嵌套引用` | 引用块；重复引用标记表示嵌套。 | 标准语法 |
| `- 项目`；`* 项目`；`+ 项目` | 无序列表；标记后留一个空格。 | 标准语法 |
| `1. 项目`；`2. 项目` | 有序列表；数字后加句点和空格。 | 标准语法 |
| `- 父项` ↵ `    - 子项` | 缩进子项，形成嵌套列表；此示例子项缩进四个空格。 | 标准语法 |
| `---`；`***`；`___` | 分隔线；独占一行，建议与前后正文用空行隔开。 | 标准语法 |
| `` `代码` `` | 行内代码；内部 Markdown 标记不解析。 | 标准语法 |
| ``` ``含有 ` 的代码`` ``` | 使用双反引号包裹包含单反引号的行内代码。 | 标准语法 |
| ```` ```python ```` ↵ `print("hello")` ↵ ```` ``` ```` | 围栏代码块（CommonMark）；围栏独占一行，语言名可省略。 | 标准语法 |
| `~~~python` ↵ `print("hello")` ↵ `~~~` | 波浪号围栏代码块（CommonMark）；开闭围栏使用同一种字符。 | 标准语法 |
| `    print("hello")` | 缩进代码块；每行开头缩进四个空格或一个制表符。 | 标准语法 |
| `[文字](https://example.com)` | 链接。 | 标准语法 |
| `[文字](https://example.com "提示")` | 带悬停提示的链接。 | 标准语法 |
| `[文字][标识]` ↵  ↵ `[标识]: https://example.com "提示"` | 引用式链接；正文引用标识，另行定义地址与可选提示。 | 标准语法 |
| `![说明](assets/image.png)` | 图片；方括号为替代文字，圆括号为图片路径或地址。 | 标准语法 |
| `![说明](assets/image.png "提示")` | 带悬停提示的图片。 | 标准语法 |
| `<https://example.com>`；`<name@example.com>` | 自动链接；地址或邮箱使用尖括号包裹。 | 标准语法 |
| `[跳转](#section-id)` | 页内链接；跳转到指定 ID。 | 标准语法 |
| `\*`；`\#`；`\[`；`\\` | 反斜杠转义；将有语法意义的标点作为普通字符显示。 | 标准语法 |
| `&amp;`；`&lt;`；`&gt;`；`&#169;` | HTML 实体；分别表示与号、小于号、大于号、版权符号。 | 标准语法 |
| `<br>` | HTML 换行；MDRE 可用于表格单元格内换行。 | 标准语法 |
| `<span>文字</span>`；`<div>内容</div>`；`<!-- 注释 -->` | 原始 HTML 与注释属于 Markdown 标准；MDRE 对一般 HTML 片段保留源码，不作为任意 HTML 执行。 | 标准语法 |
| `~~删除线~~` | 删除线；GFM 等常用扩展。 | 通用扩展 |
| `- [ ] 未完成`；`- [x] 已完成` | 任务清单；GFM 等常用扩展。 | 通用扩展 |
| `\| 名称 \| 数值 \|` ↵ `\| --- \| --- \|` ↵ `\| 示例 \| 123 \|` | 管道表格；表头与数据之间必须有分隔行。 | 通用扩展 |
| `\| :--- \| :---: \| ---: \|` | 表格分隔行中的冒号分别表示左对齐、居中、右对齐。 | 通用扩展 |
| `A \\| B` | 表格单元格内的竖线需使用反斜杠转义；位于行内代码中的竖线也应转义。 | 通用扩展 |
| `==重点==` | 默认颜色高亮，部分编辑器支持。 | 通用扩展 |
| `x^2^`；`H~2~O` | 上标与下标；Pandoc 等常用扩展，MDRE 要求标记内非空且不含空白。 | 通用扩展 |
| `$x^2 + y^2 = z^2$` | 行内 LaTeX 数学公式；MDRE 使用 KaTeX 渲染。 | 通用扩展 |
| `$$` ↵ `\frac{a}{b}` ↵ `$$` | 块级 LaTeX 数学公式；MDRE 要求开闭 `$$` 各独占一行。 | 通用扩展 |
| `$$` ↵ `E = mc^2 \tag{1}` ↵ `$$` | 块级公式编号；`\tag{1}` 显示带括号编号，`\tag*{1}` 显示不带括号编号。 | 通用扩展 |
| ```` ```mermaid ```` ↵ `graph TD` ↵ `A --> B` ↵ ```` ``` ```` | Mermaid 图表代码块；渲染为图表，可在源码栏修改，或双击图表打开源码编辑器。 | 通用扩展 |
| `文字[^注1]` ↵  ↵ `[^注1]: 脚注内容` | 脚注引用与定义；MDRE 按首次引用顺序编号。 | 通用扩展 |
| `[toc]` | 文档内目录；必须独占一段，按标题生成，其他编辑器的目录标记可能不同。 | 通用扩展 |
| `## 标题 {#section-id}` | 显式标题 ID；Pandoc 等常用扩展，可用 `[跳转](#section-id)` 引用。 | 通用扩展 |
| `---` ↵ `title: 文档标题` ↵ `author: 作者` ↵ `---` | YAML front matter；位于文首，存放元数据。MDRE 导出时不输出，可使用 `title` 作为默认文件名。 | 通用扩展 |
| `![说明](image.png){width="4in"}` | Pandoc 风格图片尺寸属性；接受带 `px`、`in`、`cm`、`mm`、`pt` 单位的正数 `width` 或 `height`。`width` 换算为像素用于显示；`height` 保留在源码中，显示时仍保持图片宽高比。 | 通用扩展 |
| `{color:#e5484d}文字{/color}` | 文字颜色：#RGB、#RRGGBB 或 red/blue/green/yellow/orange/purple/black/white/gray/grey。 | MDRE 扩展 |
| `{bg:#fff3b0}文字{/bg}` | MDRE 指定高亮背景色；取值规则同文字颜色。 | MDRE 扩展 |
| `{size:1.25em}文字{/size}`；`{size:18px}文字{/size}` | 字号：使用大于 0 的有限数值，并附加 `em` 或 `px` 单位。 | MDRE 扩展 |
| `![说明](image.png){w:400}` | 图片宽度：正整数，单位 px。 | MDRE 扩展 |
| `{color:red}{bg:yellow}文字{/bg}{/color}` | 样式可嵌套，按相反顺序闭合；不符合语法要求的标签按原文显示。 | MDRE 扩展 |

## 下划线

下划线采用通用 HTML 写法 `<u>文字</u>`。编辑器将其作为可编辑文字格式处理，可与粗体、颜色、公式组合；该写法使用 HTML 标记，不使用专用 Markdown 定界符。代码块或行内代码中的标记按普通代码文本显示。
