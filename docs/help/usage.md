# MDRE for VS Code 使用说明

本页说明 **MDRE for VS Code 0.2.5** 的功能与操作方法。

## 打开与编辑

打开 Markdown 文件后，在命令面板运行“MDRE: 打开双栏编辑器”，或选择“重新打开编辑器方式 → MDRE 双栏编辑器”。支持 `.md` 和 `.markdown` 文件。默认不将 MDRE 设为 Markdown 文件的默认编辑器。

保存、自动保存、撤销和重做由 VS Code 原生文档管理。文件夹、文件标签及启动恢复由 VS Code 工作区管理。扩展不会建立独立的桌面文件管理器。

扩展默认仅显示富文本编辑器；视图工具组中的分栏图标可显示／隐藏源码栏。两栏均可编辑，并保持内容同步。“默认显示源码栏”设置可调整初始显示方式。

## 格式、公式与图表

编辑工具按历史、字体、色彩、段落、插入、结构分组，按钮保持一行，下方显示类别名；窄窗口可横向滚动工具栏。文本渲染保留连续空格，源码与富文本同步编辑。

| 功能 | 方法 |
| --- | --- |
| 标题、列表、引用、链接 | 工具栏或右键菜单 |
| 表格 | 插入表格；直接编辑单元格；右键插入／删除行列，以及列宽、对齐、合并／拆分等操作，见下文“表格操作” |
| 下划线 | 字体工具组的 U 按钮、Ctrl+U 或右键菜单；源码使用 HTML 标记 `<u>内容</u>` |
| 数学公式 | 行内公式使用 `$…$`；块级公式的起止 `$$` 标记分别独占一行。双击公式进入 MathLive 可视化编辑 |
| Mermaid | 插入图表，双击修改源码；支持删除 |
| 代码块 | 语法高亮、固定行号和语言切换；展开后的可视区域最多容纳约 20 行，超出部分可在代码块内滚动查看。阅读模式可折叠／展开，设置页可选择浅色或深色主题 |
| 图片 | 插入按钮、拖入原文件、文件粘贴优先直接引用原文件绝对路径；截图等没有原文件的图片先保存在持久图片目录。默认等比适应正文宽度，原始尺寸模式恢复指定宽度。相对路径继续支持，assets 仅作兜底，未保存文档也能插图。 |
| 文字颜色与高亮 | 点击预选色块应用，打开色板更换颜色；右键菜单可应用、选色、恢复文字颜色或清除高亮 |
| 源码片段 | 已有 HTML、front matter 等内容可通过源码片段入口修改；右键插入菜单不提供“HTML 块”和“内联 HTML”入口 |

## 表格操作

表格在富文本中直接编辑。列宽、对齐与单元格结构通过鼠标拖动或右键“表格”菜单操作，一次操作算一步撤销。

| 操作 | 方法 |
| --- | --- |
| 调整列宽 | 将鼠标移到表格列边框，光标变为左右拖动箭头后按住拖动；拖动时实时预览（单列最小 4%、总宽保持 100%），松开后一次提交。双击列边框按该列内容自动适应宽度，其余列按现宽比例分配剩余空间。 |
| 列宽菜单 | 右键“表格”菜单中的“均分各列／适应内容／恢复自动列宽”三项。列宽百分比保存在表格后的注释中，其他 Markdown 编辑器会当作注释忽略。 |
| 水平对齐 | 右键“表格 → 左对齐／左右居中／右对齐”，三者互斥，勾选表示当前状态。GFM 表格的对齐写入分隔行（`:---`／`:---:`／`---:`），只影响选中单元格所在列，其余列保持原对齐；HTML 表格写入单元格 `text-align` 样式。 |
| 上下居中 | 右键“表格 → 上下居中”勾选。该项为独立开关，可与任一水平对齐同时生效。 |
| 选择单元格 | Ctrl 或 Cmd+单击切换单元格多选；Shift+单击从锚点按矩形范围选择；“全选表格”选中整表；也可在渲染栏拖选跨单元格的文字后操作，按选区覆盖的单元格处理。 |
| 合并单元格 | 选中矩形区域后右键“表格 → 合并单元格”。合并内容按阅读顺序用换行连接；非矩形区域等不合法选择会提示并且不修改文档。 |
| 拆分单元格 | 右键“表格 → 拆分单元格”。拆分后内容保留在左上单元格。 |
| 转换为 Markdown 表格 | 仅无合并、无上下居中的 HTML 表格可用：右键“表格 → 转换为 Markdown 表格”。执行前会列出会丢失的信息并需确认；列宽保留为 HTML 注释，水平对齐按每列首行写回分隔行。 |

首次合并单元格或首次启用“上下居中”时，整表会转为 HTML 表格，状态栏提示“此表已转为 HTML 表格，其他仅支持标准 Markdown 表格的编辑器可能显示源码”。GFM 表格的列宽以 HTML 注释保存在表格后，例如 `<!-- mdre:table-widths: 25%,40%,35% -->`；插删列会同步更新注释，列数或注释数量不匹配时回退自动布局并提示。HTML／PDF 导出会保留列宽、合并单元格与水平／垂直对齐。

## 侧栏

“侧栏”图标或 Ctrl+Shift+O 收起／展开左侧区域；提示随当前状态变化。侧栏提供“图片管理”和“大纲导航”，点击对应按钮切换。

### 图片管理

点击“图片管理”后，面板按当前富文本文档的引用顺序列出所引用的图片。

| 操作 | 方法 |
| --- | --- |
| 查看图片列表 | 列表显示图片名称与图片在电脑中的路径；名称过长时以省略号显示，悬停可查看完整内容。图片较多时可在面板内滚动查看。 |
| 跳转引用位置 | 单击条目，编辑器滚动到对应图片并选中该图片位置。 |
| 打开所在目录 | 双击图片名称，由 VS Code 在系统文件资源管理器中打开图片所在目录。 |
| 空状态 | 当前文档没有引用图片时，面板显示空状态提示。 |

面板随文档切换与预览刷新自动更新。网络图片显示原始 HTTPS 地址，内嵌图片显示“内嵌图片（data URI）”，这两类图片没有本地目录可打开。

### 大纲

大纲按标题层级导航，点击标题跳转到对应章节。条目保持原有高度，标题较多时通过列表滚动查看。标题旁箭头折叠／展开大纲并保留面板，侧栏右缘可拖动调整宽度，也可在设置中输入宽度。

## A4 与分页

A4 图标切换纸张显示，纸张尺寸为 **210 × 297 mm**。设置 → 纸张与图片可选择连续或分页排版；编辑和阅读模式均可使用。

分页先按固定纸张尺寸排版，再整体缩放。Ctrl+滚轮缩放 25%–250%；按渲染栏宽度每行自动排列 1–3 页，从左到右、从上到下递增。每页底部显示页码，右下角显示可见页／总页数与缩放比例；连续排版只显示缩放比例。三列时页码依次为第一行 1、2、3，第二行 4、5、6；可用高度不影响列数。

A4 正文对齐可选择左对齐、居中、右对齐、两端对齐，默认两端对齐。长段落、列表和表格按视觉行、列表项和表格行跨页；特别高的不可分块使用块内滚动。布局装饰、页码和页间空白不写入 Markdown，也不增加撤销步骤。

## 导出

顶部“导出”菜单保存 HTML 或 PDF，嵌入本地图片和公式字体。PDF 调用系统 Edge 或 Chrome；自动检测失败时，在 VS Code 设置中填写 `mdre.pdf.browserPath`。

“导出”菜单还提供“导出可分享副本…”：把当前文档与被引用的图片打包为一个 zip 文件，Markdown 中的图片引用改写为 zip 内的相对路径，原文档与源图片不变。扩展通过 VS Code 的保存对话框询问 zip 保存位置。原本位于文档目录内、使用相对路径的图片保持原相对路径；绝对路径与全局图片库中的图片按内容哈希命名放入 zip 内的 `images/` 目录；无法读取的图片跳过并在状态栏提示数量。HTTPS 与 data URI 图片不写入 zip；导出成功后在状态栏显示保存路径与文件大小。

## 复制与粘贴

渲染栏右键菜单的“复制／剪切／粘贴”区域提供“复制为富文本”（**Ctrl+Shift+C**）：有选区时复制选区，无选区时复制整篇渲染内容；同时写入富文本与纯文本两种格式，粘贴到 Word、邮件或网页编辑器时保留标题、段落、粗体、斜体、下划线、删除线、列表、任务清单、引用、代码、链接、表格和图片。源码栏的复制行为保持不变，仍输出纯 Markdown。MDRE 私有语法按最接近的语义降级：文字颜色处理为下划线，高亮与字号处理为加粗；无法映射的内容丢弃并在状态栏提示。

源码栏与渲染栏都可使用 **Ctrl+V** 粘贴。剪贴板包含 HTML 时自动转换为 Markdown，没有 HTML 或转换失败时按纯文本粘贴；不新增顶部按钮和设置项，转换结果与忽略项通过状态栏提示。

| 内容 | 处理方式 |
| --- | --- |
| 标题、段落、列表、引用、代码块、链接、表格、换行 | 转换为对应 Markdown；代码块保留语言。 |
| 粗体、斜体、下划线、删除线、任务清单 | 转换为对应 Markdown 标记。 |
| Word 的 `MsoHeading*` 标题与 `mso-list` 列表、Excel 或网页表格 | 按结构识别并转换。 |
| 颜色、字体、字号、行距、对齐等 | Markdown 无法表达，忽略并提示“已忽略 N 项格式”。 |
| 合并单元格表格 | 降级为普通段落或文本并提示。 |
| 脚本、iframe、事件属性 | 转换前做白名单清洗，一律丢弃。 |
| Word 内嵌 data URI 图片 | 存入扩展的全局图片库（按内容哈希去重、引用绝对路径）。 |
| 网页 HTTPS 图片 | 保留链接；离线后可能无法显示。 |
| 无法读取的 Word 临时文件图片 | 跳过并提示数量。 |

粘贴内容体积过大或图片过多时会回退为纯文本：HTML 超过 5 MB 或图片超过 20 张时按纯文本粘贴并提示。源码栏按光标插入，渲染栏按选区替换；一次粘贴只产生一步撤销。输入法组合输入期间先提交再粘贴；代码块和行内代码内粘贴按纯文本处理，表格单元格内粘贴复杂内容按文本处理。右键“粘贴”菜单同样优先进行 HTML 转换，插件版右键粘贴依赖 VS Code 剪贴板读取能力，Ctrl+V 最可靠。

## 设置与帮助

可设置主题、默认模式、字体、字号、行距、源码宽度、代码块主题和快捷键。“纸张与图片”设置默认 A4、连续／分页排版、A4 正文对齐和图片显示方式；“侧栏导航”设置侧栏宽度及大纲折叠状态。保存后应用并保留配置；取消或 Esc 放弃本次修改。

设置弹窗会按窗口空间调整尺寸，可拖动标题移动位置、拖动右下角调整大小。

帮助中提供完整语法表及第三方声明。文件关联、独立恢复目录及保存前备份管理属于桌面版功能；本扩展使用 VS Code 原生文档与工作区机制。

工具栏超出窗口时，可用滚轮横向浏览：向后（向下）向右，向前（向上）向左。专注模式出口在右上角，纸张页码与缩放信息在右下角。图片选择“适应正文宽度”时等比填满所在正文容器，包括带自定义宽度的图片；原始大小模式恢复源码指定宽度。

A4 显示源码时，两栏按可见文字位置双向滚动联动，兼容连续排版、分页、多列缩放及长段落跨页；另一栏的镜像滚动不会反向驱动。

## 操作提示

右键菜单将文字格式、插入、文字颜色、高亮、字号、表格和块操作分组。常用的复制、剪切、粘贴、撤销、重做保留在一级；上移、下移、删除、转换当前块及源码片段入口放在“块操作”中。正文不再跟随鼠标显示块操作悬浮条。

分隔线直接显示横线；HTML 显示预览，不在正文中展开源码框。需要修改时使用源码栏或“块操作 → 编辑源码片段”。代码块仍可直接编辑代码内容，公式与 Mermaid 沿用专用弹窗。

编辑和阅读模式均显示完整编辑工具；阅读模式将修改功能置灰，仍可查找、复制、导出、设置 A4 和缩放。页内链接可直接单击，包含显式标题 ID 的链接与文档目录共用标题锚点。

设置页按三列排列，窗口较窄时自动减少列数。主题保存后立即生效并在重新打开后恢复；桌面版“跟随系统”跟随操作系统，插件版优先跟随 VS Code 的主题。

插件顶部直接显示编辑工具栏，最右侧提供设置和导出图标；帮助位于设置窗口左下角。文件操作、标签与文档保存使用 VS Code 原生界面和命令。

## 0.2.5 图片、剪贴板与表格操作

- 侧栏新增“图片管理”（与“大纲导航”同区），按引用顺序列出当前文档的图片，单击跳转、双击打开所在目录。
- 导出菜单新增“导出可分享副本…”，把文档与被引用图片打包为 zip。
- 渲染栏右键新增“复制为富文本”（Ctrl+Shift+C）；源码栏与渲染栏粘贴 HTML 时自动转换为 Markdown。
- 表格新增列宽拖拽与菜单、水平对齐与上下居中、合并／拆分单元格、转换为 Markdown 表格；列宽以 `<!-- mdre:table-widths: … -->` 注释保存，合并或上下居中的表格保存为 HTML 表格。详见“表格操作”。

## 0.2.4 视图、字号与编辑操作

右下角“选择视图模式”提供以下组合。手动更改为其他组合时显示“自由模式”。重新打开时恢复最后的组合，包括自由模式。

| 视图 | A4 | 源码栏 | 侧栏 | 编辑功能区 |
| --- | --- | --- | --- | --- |
| 全量编辑 | 关闭 | 显示 | 显示 | 显示 |
| 专注模式 | 开启 | 隐藏 | 显示 | 隐藏 |
| 沉浸专注 | 开启 | 隐藏 | 隐藏 | 隐藏 |
| A4视图 | 开启 | 隐藏 | 显示 | 显示 |

设置提供“默认侧栏状态”和“编辑功能区显示状态”。专注模式保留底部信息栏，可切换视图；F11 在专注模式与全量编辑间切换。插件隐藏编辑功能区时，导出及设置图标出现在右下角。

“外观与阅读 → 字号单位”选择 px 或 em，初始为 px。切换时正文字号按 16px = 1em 换算，视觉大小保持一致。字号按钮与右键预设仅显示所选单位；px 提供 8px 至 24px、间隔 2px 的预设。

右键顺序为“文字格式 → 文字颜色 → 标题 → 高亮 → 字号 → 插入 → 表格 → 块操作”。在表格中拖选文字范围，或 Ctrl／Cmd 点击多选单元格、Shift 点击选择矩形区域，再右键设置对齐；“表格 → 全选表格”可统一全表对齐。未选格的对齐保持原样，批量操作可一次撤销。

空列表项按 Backspace 或 Enter 可退出列表。分隔线可点击选中后按 Delete／Backspace 删除。普通段落的数字句点可写为 `1\. 说明`；`1. 说明` 与独占一行的 `1.` 按 Markdown 规则表示有序列表。旧数字实体继续兼容。复杂列表内额外空段会以 HTML 空段 `<p></p>` 保存，避免丢失段落层级。

查找提供上一个和下一个匹配，Enter 向后、Shift+Enter 向前；自动滚动到当前匹配。

有正式路径的修改文档每 60 秒自动保存，插件通过 VS Code 文档保存确认。无路径文档应先手动保存；组合输入、恢复副本、冲突中的文档会暂缓。底部左侧按“文件名 | 保存状态”排列，右侧为字符与词数、编码、行列、视图选项、编辑／阅读模式。

PDF 导出先选择“分页导出”或“长页导出”。前者使用 A4 分页，后者将全文排在一张纵向长页中。长页超过系统打印引擎上限时会提示使用分页导出。HTML 导出流程不变。
